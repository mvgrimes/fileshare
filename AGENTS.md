# AGENTS

- The implementation plan/source of truth for roadmap decisions is `PLAN.md`.
- Session handoff context is in `data/SESSION_LOG_*.md`.
- For migrations, `libsql://` URLs are intentionally not supported by the current Goose SQLite migration path; use a local SQLite file for migration commands.
- Issue tracking uses the `ticket` CLI (`tk`); create and manage roadmap work items with `tk` commands.
- Database schema changes are managed by `goose` migrations.
- Database queries are generated by `sqlc`.
- Use `pnpm` (not `npm`) for frontend/package management in this repo.
- When installing or adding Node dependencies, always run `pnpm` through Socket Firewall with the `sfw` prefix (for example: `sfw pnpm install`, `sfw pnpm add <pkg>`).
- There is a side process running `pnpm run css:watch` which is compiling the tailwindcss as things change in our html/templates. If the ./internal/web/assets/dist/app.css files is changed after working on a ticket, include it in the git commit.
